USDCraft：用程序化建模生成可仿真的 Articulated 3D Assets

USDCraft 解决的是 Real2Sim 中一个很实际的问题：真实物体的扫描 Mesh 往往不完整，也没有零件划分、关节类型和物理参数。仅靠 Mesh Segmentation 很难把它恢复成可以在 Isaac Sim 中运动的 articulated asset。

USDCraft 不让 LLM 一次性输出最终 Mesh，而是让它生成一个可执行的 Asset Program。程序描述几何零件、连接关系、Revolute 或 Prismatic Joint、质量、摩擦和关节限制，最后编译为 USD/PhysX 资产。

1. 先把几何变成 LLM 能使用的证据

原始 Mesh 直接交给语言模型并不方便。USDCraft 会把它转换成可度量的文本和结构化信息，例如分层切片、几何边界、开口、凸起和区域尺寸。

一个关键处理是区分“已观测表面”和“未知空间”。扫描没有看到的区域不一定是空洞，也可能只是被遮挡或位于物体内部。如果把未知区域直接当成空白，模型很容易错误地删除零件或关节结构。

2. 用程序迭代修改资产

每次 LLM 生成或修改程序后，系统都会重新构建模型，并与源几何做数值比较。设源几何的观测表面为 (S_M)，候选模型表面为 (S_t)：

Dt−=SM∖St,Dt+=St∖SM D^-_t=S_M\setminus S_t,\qquad D^+_t=S_t\setminus S_M Dt−​=SM​∖St​,Dt+​=St​∖SM​(D^-_t)

这种反馈让 LLM 可以针对具体几何缺口修改程序，而不是凭一次生成结果猜测哪里错了。程序化表示还保留了局部修改能力，例如只调整一个零件的尺寸或关节轴。

3. 直接写入仿真物理属性

USDCraft 使用 CadQuery、SDF 等工具构建参数化几何，再把质量、摩擦、关节限制和连接关系写入 USD/PhysX 定义。这样生成的结果不只是可视化模型，而是可以被仿真器加载并驱动的物理资产。

这一步也提醒我们，几何恢复和物理恢复是两件事。程序能够描述质量和摩擦，并不代表这些参数已经从扫描中真实测量出来。

4. 实验结果

在 USDCraft-bench 上，Astra 版本达到 84.83% 的 Part Matching F1，Articraft-Astra 对照为 64.04%。Joint Axis Angular Error 为 6.83°，对照为 15.11°。

结果说明，程序化建模加上几何重检查，能够更准确地恢复物体零件和关节轴。相比一次性生成 3D 模型，系统的每一步都有可解释的数值反馈。

5. 对 Real2Sim 的启发

USDCraft 代表了一种很有代表性的闭环：LLM 负责提出结构化程序，工具负责编译和测量，数值反馈再推动下一轮修改。

对于机器人仿真，最有价值的输出不一定是外观最逼真的 Mesh，而是一个能被控制、能表达关节关系、能被局部修正的资产。程序化表示也方便后续把尺寸、关节限制和碰撞几何暴露给仿真随机化流程。

6. 局限与判断

Part Matching 和关节轴误差较低，并不代表仿真中的接触动力学已经接近真实世界。质量分布、摩擦系数、材料柔性、装配间隙和碰撞形状仍然需要现实数据校准。

对于 contact-rich manipulation，错误的摩擦和接触参数可能比几何误差更快地导致策略失效。因此 USDCraft 更适合被看作自动化资产构建和结构恢复工具，而不是完整的 sim-to-real 解决方案。
