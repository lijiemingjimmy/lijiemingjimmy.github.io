Skill2Real：通过 Agentic Skill Learning 实现 Zero-Shot Sim-to-Real

Skill2Real 研究如何让 Agent 在仿真中学习可执行技能，并把技能知识直接迁移到真实机器人，不再依赖真机任务微调或更新技能记忆。

它的重点不在于发明一个新的低层 Policy，而在于组织技能学习、失败诊断、验证、持久化记忆和跨域执行。系统希望保存的是可以被再次调用的技能程序，而不是只能在某个仿真状态下复现的关节轨迹。

1. Cerebellum 与 Brain

Skill2Real 把 Skill Memory 分成两个层次：

  • Cerebellum：学习局部操作技能，例如抓取、放置和靠近物体；
  • Brain：在冻结 Cerebellum 的情况下，学习多阶段任务如何组合和调用局部技能。

这种分层避免每次出现新任务都重新训练底层控制器。只要局部技能已经具备一定鲁棒性，高层 Agent 就可以通过组合和条件判断解决更长的任务。

2. Shared Robot API 是跨域边界

仿真和真实机器人通过语义一致的 Shared Robot API 提供观察和操作接口。具体的视觉处理、标定、运动控制和硬件通信由各自后端负责，Agent 学到的是依赖公共观测和 API 语义的程序。

这点非常关键。若技能程序直接读取仿真中的精确物体位姿、碰撞信息或其他 privileged state，迁移到真实机器人时就会失效。因此训练期可以用特权状态做 Verifier，但这些信息不能泄漏进部署时真正执行的技能。

3. Proposer-Verifier-Governor 闭环

Skill2Real 使用 PVG 流程：

  1. Proposer 根据目标、公共观测和 Skill Memory 生成技能程序；
  2. Simulator + Verifier 执行程序，用仿真证据诊断错误并产生受约束反馈；
  3. Governor 检查候选改动是否可靠，决定是否更新技能记忆；
  4. 经过多轮迭代后，把通过验证的技能保存下来。

Verifier 和 Governor 的分工很重要。前者负责判断执行发生了什么，后者负责决定什么结果值得进入长期记忆。否则一次偶然成功或利用仿真漏洞的程序可能污染整个技能库。

4. 实验结果

在 LIBERO-90 中学习技能后，不针对 LIBERO-Pro Long 重新训练，使用另一 Agent 评估冻结技能库，Pro Long 成功率从 2.0% 提升到 56.3%。

在 Robosuite 的 7 项任务中，使用不同模型学习技能，平均成功率为 85.1% 和 89.4%。把仿真中得到的冻结技能迁移到真机后，四项操作任务的平均完成进度达到 78.75%，不需要真机任务策略微调或更新技能记忆。

消融结果也支持闭环设计：移除 Verifier 和 Governor 后，最终 Pro Long 成功率分别下降 17.3 和 13.3 个百分点。这说明技能学习不能只有提案，还需要失败诊断和记忆管理。

5. 为什么它能做 Sim-to-Real

Skill2Real 的迁移单位不是原始关节动作，而是 API 层面的程序知识。仿真和真实后端只要对“观察物体、抓取、放置、检查状态”等语义提供一致接口，Agent 就可以复用技能结构。

这是一种软件抽象边界上的 Sim-to-Real。它降低了对完全相同的传感器和动力学的要求，但也把迁移成败交给 API 是否真的覆盖了任务所需的信息。

6. 局限与判断

Shared API 如果设计得过于具体，技能仍然会绑定某一类机器人；如果设计得过于抽象，又可能隐藏操作所需的接触、可达性和失败状态。仿真 Verifier 也可能把现实中不可靠的判断当作成功标准。

因此，Skill2Real 不能简单理解为任意机器人都能零样本迁移。它更像是一种把技能学习组织成可验证软件系统的方法：底层能力负责执行，高层 Agent 负责组合，Verifier 负责提供证据，Governor 负责控制记忆质量。

对后续研究来说，技能库除了程序本身，还应该保存适用的初始状态、失败模式、恢复策略、验证条件以及与其他技能的组合方式。这样积累的才是可持续复用的经验。
