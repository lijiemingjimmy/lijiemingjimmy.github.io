ALPS：世界模型需要什么样的视觉状态编码器？

世界模型通常先把图像编码成 latent，再预测动作会怎样改变 latent。如果第一步已经丢掉物体的位置、姿态或局部关系，后面的动力学模型就很难把这些信息重新找回来。

ALPS 关注的就是这个起点：同一套视觉 token，能不能既保留物理状态，又与语言对齐，还能被解码回图像？

论文：ALPS: Visual State Encoders for World Models，2026 年 10 月 21 日，UCSC、UCSB 与 Google 合作。本文根据所提供的解读整理，并核对原论文 v1 的方法和主要实验。论文｜项目｜代码

1. 先看清它在系统里的位置

ALPS 的名字是 A Language-aligned, Pixel-renderable State encoder。它训练的是视觉编码器，下游再接状态探针、策略、动力学模型或图像解码器。

用简化的单步形式表示：

zt=E(ot),z^t+1=F(zt,at),o^t+1=D(z^t+1). z_t=E(o_t),\qquad \hat z_{t+1}=F(z_t,a_t),\qquad \hat o_{t+1}=D(\hat z_{t+1}). zt​=E(ot​),z^t+1​=F(zt​,at​),o^t+1​=D(z^t+1​).

其中，EEE 提供状态表征，FFF 学习动作条件下的变化，DDD 把预测变成可查看的画面。实际动力学模型还可以使用历史上下文。

ALPS 主要改进的是 EEE。 视觉编码器预训练使用静态图像与文本，不依赖机器人动作标签或时序交互监督；但下游动力学和策略仍然需要各自的训练数据。

这一区分很重要：“静态图像预训练得到的特征适合动力学学习”，不等于“模型仅看静态图像就学会了动作引起的物理变化”。

2. 三种能力为什么需要一起考虑？

能力 对下游的作用 仅靠这一项可能遗漏什么
物理状态信息 区分位置、姿态和空间关系 不一定有直接可用的语言接口
语言对齐 把指令、目标和场景联系起来 全局语义相似，不代表局部位置准确
像素可恢复性 把观察和预测渲染出来检查 重建细节丰富，不保证动作相关信息更好

例如，两张“机械臂抓杯子”的图像可能有相同语义，但杯子是否已经离开桌面，对控制很关键。反过来，背景纹理重建得非常准确，也未必有助于判断杯子是否抓稳。

ALPS 希望在这三者之间取得平衡。它的贡献应当从整体接口和下游效果判断，不需要每一个单项指标都超过专门优化该指标的模型。

3. 第一阶段：让同一套 patch token 接受四种监督

模型采用 ViT-B/16。在 224×224224\times224224×224 输入下，输出 196 个、每个 768 维的 patch token。

第一阶段从零训练，目标为：

L1=LITC+LCap+wrecLRec+0.25LDense. \mathcal L_1 =\mathcal L_{\mathrm{ITC}} +\mathcal L_{\mathrm{Cap}} +w_{\mathrm{rec}}\mathcal L_{\mathrm{Rec}} +0.25\mathcal L_{\mathrm{Dense}}. L1​=LITC​+LCap​+wrec​LRec​+0.25LDense​.

四项损失各有分工：

  • 图文对比： 让匹配的图像和文本在全局表示上接近。
  • 描述生成： 从视觉 token 生成详细 caption，补充语义细节。
  • 像素重建： 从干净或加噪 token 重建原图，保留可恢复的视觉信息。
  • 稠密对应： 利用裁剪、缩放和翻转的已知关系，约束对应位置的局部特征。

重建项包含 L1、结构相似度和图像梯度相关项。稠密对应使用局部对比学习：同一区域在不同增强视图中的对应特征作为正样本，其他位置或图像的特征作为负样本。论文 §3.1

可以把这一阶段理解成同时提出三个要求：知道画面在说什么，保留画面长什么样，并且分得清信息来自哪里。

数据使用 DataComp-1B 图文对与合成详细描述。训练先在 128 分辨率处理约 128 亿次样本，再在 224 分辨率处理约 10 亿次样本。这里是累计样本处理次数，不能写成 138 亿张独立图片。

4. 第二阶段：有几何对应关系的跨视图自蒸馏

这是最值得仔细看的部分。第一阶段已经有语言和像素能力，第二阶段希望进一步改善局部状态表征。

Teacher 和 Student 都从第一阶段初始化，但 Teacher 保持冻结。对同一张图像：

  1. Teacher 接收干净裁剪 BBB。
  2. Student 接收经过颜色、模糊等增强的裁剪 AAA。
  3. Predictor 读取 Student token 和几何查询 qiq_iqi​，预测 Teacher 的目标 patch 特征。

几何查询告诉 Predictor：目标位置在 Student 裁剪中的哪里，以及两种裁剪的相对尺度。模型不必自行猜测两个视图的对应关系，可以把学习重点放在局部内容的稳定表示上。

训练目标为：

L2=1∣V∣d∑i∈V∥P(Estudent(A),qi)−zˉiteacher(B)∥22. \mathcal L_2= \frac{1}{|V|d}\sum_{i\in V} \left\| P(E_{\mathrm{student}}(A),q_i) -\bar z^{\mathrm{teacher}}_i(B) \right\|_2^2. L2​=∣V∣d1​i∈V∑​​P(Estudent​(A),qi​)−zˉiteacher​(B)​22​.

zˉ\bar zzˉ 是标准化后的 Teacher 特征，VVV 是 Teacher patch 中心落在 Student 裁剪范围内的位置集合。监督只覆盖符合这个条件的位置，不要求 Student 凭空恢复不可见区域。论文 §3.2

例如，同一个杯子在大裁剪里与整张桌面一起出现，在小裁剪里只剩杯子和一小块桌面。Student 要在上下文、尺度和外观发生变化后，仍提供足够好的局部信息，让 Predictor 恢复对应 Teacher 特征。

这里的 cross-view 是同一图片的增强视图，不应直接理解成真实多相机或三维视角监督。

第二阶段处理约 500 万次单图采样，完成后丢弃 Predictor，保留 Student，并继续使用第一阶段的文本编码器和图像投影层。它是建立在昂贵第一阶段上的追加训练，不能把整个方法的成本概括成“只训练了 500 万张图”。

5. 为什么空间能力增强后，语言能力还能保留？

论文将类似的第二阶段训练应用到 CLIP 和 SigLIP 2，也改善了状态探针结果，但原来的图文对齐下降更明显。ALPS 的变化则较小。

作者提出的解释涉及全局语言接口：ALPS 使用线性投影与 patch 平均池化，因此

W(1N∑izi)=1N∑iWzi. W\left(\frac{1}{N}\sum_i z_i\right) =\frac{1}{N}\sum_i Wz_i. W(N1​i∑​zi​)=N1​i∑​Wzi​.

如果局部更新的均值接近零，即 ∑iΔzi≈0\sum_i\Delta z_i\approx0∑i​Δzi​≈0，patch 特征可以改变，而全局图像表示变化较小。

这个解释提供了一个值得研究的机制，但线性恒等式本身不能证明训练一定产生零均值更新，也不能保证其他任务上的语义始终不变。这里应保留“可能解释实验现象”的定位。

对模型设计更直接的启发是：局部状态表征如何更新、全局语义如何读取，可能需要一起考虑。只看局部特征变强，很容易忽略原来语言接口已经发生漂移。

6. 三类下游实验，要分别理解

状态探针：信息能不能被读出来？

冻结视觉编码器，训练约 2.5M 参数的轻量 Probe，读取过去 16 帧特征。它既评估当前状态读取，也评估给定未来真实机器人动作后，预测 1 秒或 3 秒之后状态的能力。

平均相对位置误差以 ALPS Stage 1 为基准：

编码器 相对误差，越低越好
ALPS Stage 1 1.000
ALPS 0.829
V-JEPA 2-L 0.829
C-RADIOv3-B 0.864
DINOv3-B 0.870
SigLIP 2-B 1.160

0.829 对应相对第一阶段约 17.1% 的误差下降。ALPS 与更大的 V-JEPA 2-L 在该汇总指标上持平，不能据此说两者所有能力相同。后者的当前状态读取更好，ALPS 的 3 秒动作条件预测更好。论文 Table 1

这里的预测是带未来动作输入的监督任务，不等于已经实现自主规划。

策略学习：特征能不能支持动作？

冻结编码器后，使用相同结构的行为克隆策略，在四个 LIBERO suite 上训练：

语言接口 ALPS SigLIP 2
统一使用 BERT 83.4% 81.4%
使用各自文本编码器 85.5% 84.8%

85.5% 是四个 suite 的平均成功率。它支持 ALPS 是一个有竞争力的策略骨干，但 0.7 个百分点的均值差异不足以单独证明显著优势。

另一个不同的比较是：ALPS 原生文本编码器相对 BERT 的收益。三次独立训练的平均提升为 3.1 个百分点，95% 置信区间为 [-0.9, +7.1]，包含零。不要把这个区间误用成 ALPS 对 SigLIP 2 的显著性检验。论文 §5.3 与补充材料 S2

世界模型规划：预测能不能帮忙选动作？

冻结编码器，在 token 上训练动力学模型，再用 CEM 优化动作序列。PushT、Wall、PointMaze、Granular、Rope 使用 DINO-WM 框架；Reacher 使用 LeWorldModel。

任务 ALPS 结果 如何理解
PushT 成功率 90% 与 C-RADIOv3 并列最高
Wall 成功率 92% 与 DINOv2 并列最高
PointMaze 成功率 100% 所测编码器全部达到 100%
Granular Chamfer 0.176 低于 C-RADIOv3 的 0.180
Rope Chamfer 0.750 高于 C-RADIOv3 的 0.558
Reacher 成功率 78.7% 低于 DINOv3 的 86.0%

成功率越高越好，Chamfer 距离越低越好。结果体现的是跨任务的竞争力，并非全面领先。论文 Table 3

另外，在五步未来 token 的状态读取评测中，第二阶段相对第一阶段的误差下降分别为 PushT 28%、Reacher 17%、Granular 13%、Rope 11%。它说明空间表征改进可以传递到下游预测，而不只体现在静态感知指标上。

7. “预测可以看见”需要额外的解码器

评测时，作者为冻结 token 训练轻量适配器，将其映射到 SDXL VAE latent，再用冻结 VAE Decoder 生成图像。它与第一阶段用于重建训练的卷积 Decoder 是不同的组件。

因此，可视化未来的链条是：

动力学模型预测 token → 训练好的评测适配器 → VAE Decoder → 图像。

加载 ALPS Encoder 本身不等于已经具备完整图像生成能力。渲染出的预测也适合用于检查误差，不能仅凭画面看起来合理，就认定物理轨迹正确。

重建 L1 误差方面，ALPS 为 0.120，优于 SigLIP 2 的 0.264，但不及 MAE 的 0.109 和 OpenVision 3 的 0.104。这正好体现它的定位：兼顾状态、语言和像素接口。

8. 最有意思的结果，是重建与状态信息并不总是同向改善

在第一阶段十分之一预算的消融中，删除像素重建目标反而降低了状态探针误差，但重建能力变差。

这个结果提醒我们：用于控制的“好表示”和用于还原所有视觉细节的“好表示”不完全相同。有限模型容量需要在不同目标之间分配，背景纹理和对象状态可能争用表示能力。

但这也不意味着应该统一删除重建目标。如果目标包含预测可视化和模型诊断，保留像素接口有实际价值；如果只追求某类状态估计，则可以探索不同的权重。

对于 WAM，值得问的不是重建损失越大或越小是否更好，而是哪些信息必须保留、哪些变化可以忽略，以及这种取舍会怎样影响动作。

9. 对 VLA、接触操作和失败恢复的启发

以下是研究设想，不是论文已经验证的机器人能力。

可以固定同一个策略或动力学模型，分别接入 ALPS、DINOv3、V-JEPA 2，比较三类数据：正常执行、接触失败、失败恢复。

重点不只看平均位置误差，还可以检查：

  • 物体看起来位置相近，但实际处于抓稳、滑落或未接触状态时，特征能否区分？
  • 短时预测准确后，连续滚动预测是否仍保持状态一致？
  • 遇到遮挡、相机变化和新背景时，语言接口与局部状态信息是否一起稳定？
  • 用像素解码检查预测时，能否发现对动作有影响的错误，而不只是画质差异？

与 PhysWord 放在一起看，二者的着力点不同：ALPS 改善世界模型输入端的状态表征，PhysWord 用动作语义组织未来动态表示。二者能否结合，需要检查 latent 接口、训练目标和信息保留方式，不能只因为都使用 latent 就直接拼接。

目前 ALPS 的实验主要在仿真，尚未验证真实机器人部署；语言条件控制和世界模型规划也是分别评估，还没有展示语言目标、latent planning 与像素检查组成的完整闭环。

我最看重的是带几何查询的第二阶段，以及它提出的评测方式：一个视觉骨干既要让状态容易读出，也要让下游预测和控制受益，还要尽量保留原有接口。静态图像可以为这件事提供很强的起点，后续仍需要动作与时序数据来检验它的边界。
