Fleet Learning：机器人集群学习

本文根据提供的概念解读整理。

1. 什么是 Fleet Learning

Fleet Learning 指多个已部署机器人共同收集经验，并通过共享策略更新，让整个集群受益。

一台机器人遇到的问题，可以成为整个机器人集群的学习经验。

例如部署了 1000 台抓取机器人：

  1. 机器人 A 抓取透明杯子失败，系统记录视觉观测、动作和接触状态。
  2. 失败轨迹汇入共享数据平台，与其他机器人收集的数据合并。
  3. 使用模仿学习、强化学习或其他方法更新策略。
  4. 验证更新后的策略，再部署到集群。
  5. 其他机器人可能由此学会处理类似情况。

共享数据和模型更新提供了集体改进的机会，但单次失败数据并不保证所有机器人自动获得提升，仍需训练和验证。

3. 与 Continual Learning、Online RL 的区别

概念 主要关注点 与 Fleet Learning 的关系
Fleet Learning 多台机器人共享经验，通过策略更新改进集群表现 描述集群层面的学习闭环
Continual Learning 持续吸收新知识，同时避免灾难性遗忘 可用于持续更新集群共享模型
Online RL 利用与环境交互产生的数据更新策略 可以作为集群策略的训练方法
Offline RL 从已有数据学习策略 可以利用集群积累的轨迹训练
Imitation Learning 从示教或纠正数据学习行为 可以利用人工接管和成功示教数据

这些概念并不互斥。Fleet Learning 强调经验来自多个部署实例、学习成果能够共享；它不限定只能使用某一种训练算法。

4. Fleet-DAgger：共享有限的人类监督

提供材料介绍了 Fleet-DAgger: Interactive Robot Fleet Learning with Scalable Human Supervision（CoRL 2022）。

它关注的问题是：当多个机器人同时运行时，怎样共享有限的人类监督资源？

机器人需要帮助时，远程操作者可以介入；这些纠正数据再用于改进策略，使后续部署减少类似失败。其研究重点既包括从纠正数据学习，也包括如何在机器人之间分配人类监督。

这里的人类接管不只是帮助某台机器人完成当前任务，还可以成为后续集群学习的数据来源。

5. Fleet 与 Fleeting 的术语区别

在机器人集群学习语境下，应使用 Fleet Learning。

“Fleeting” 意为短暂、转瞬即逝，与 “Fleet” 的机群或集群含义不同。Fleeting Learning 并不是这里所讨论概念的标准名称；若某篇文章使用该表达，需要结合其具体定义判断。

6. 核心理解

Fleet Learning 将分散在各台机器人上的部署经验汇聚成共同的学习资源。重点是形成可重复的“收集—训练—验证—部署”闭环，使局部经验有机会转化为整个集群的能力改进。
