FoveaVLA：让 VLA 学会主动决定下一步看哪里

论文：FoveaVLA: Foveation Actions Replace the Wrist Camera in VLAs

FoveaVLA 研究的是一个很实际的问题：机器人不一定需要一台绑在手腕上的相机，VLA 也可以在生成动作的同时，预测下一次应该从外部相机画面的哪个区域获取高清视觉信息。

它把“看哪里”变成和“怎么动”并行预测的一个动作。机器人执行当前动作的同时，模型提前决定下一次观察的局部区域，再从原始高分辨率图像中裁剪出 foveal view，和完整视图一起输入下一轮策略。

整体闭环可以写成：

当前观察 → 动作片段 + 下一次关注框 → 执行动作 → 获取新的全局与局部观察。

1. 为什么要替代 wrist camera

腕部相机和末端执行器绑定，靠近物体时能够看清抓取细节，但视野会随着手臂移动。当机器人抓住杯子后准备把它放进远处的碗里，腕部相机可能仍然主要看到夹爪和杯子，真正重要的碗却不在画面中心。

外部相机可以看到整个工作空间，但如果把 1280×720 的图像直接缩放到策略输入大小，小物体、抓取点和接触关系只剩下很少的视觉 token。

FoveaVLA 同时保留两个视图：

  • Global view：缩放后的完整图像，负责全局位置和任务状态；
  • Foveal view：从原始高分辨率图像中先裁剪、再缩放的局部区域，负责抓取和接触细节。

这里“先裁剪再缩放”很关键。如果先把整张图缩小，再从小图中裁剪，就已经丢掉了原始细节。

Foveation 是软件层面的动态裁剪，不会移动真实摄像头。因此它可以弥补固定外部视角的分辨率问题，但不能看到相机原本看不到的区域，也不能解决物体被遮挡的问题。

2. 方法：动作和关注区域一起预测

FoveaVLA 基于 π0.5\pi_{0.5}π0.5​，主要由视觉语言模型和 Flow Matching Action Expert 组成。模型接收机器人状态、语言指令，以及每个外部视角的完整 RGB-D 和局部 RGB-D 图像。

它联合预测动作序列和未来的裁剪框：

πθ(At,Bt+w∣ot,ℓ)=πθ(At∣ot,ℓ)pθ(Bt+w∣ot,ℓ) \pi_\theta(A_t,B_{t+w}\mid o_t,\ell) = \pi_\theta(A_t\mid o_t,\ell) p_\theta(B_{t+w}\mid o_t,\ell) πθ​(At​,Bt+w​∣ot​,ℓ)=πθ​(At​∣ot​,ℓ)pθ​(Bt+w​∣ot​,ℓ)

其中：

  • At=(at+1,…,at+H)A_t=(a_{t+1},\ldots,a_{t+H})At​=(at+1​,…,at+H​) 是未来动作块；
  • Bt+wB_{t+w}Bt+w​ 是下一次观察使用的区域；
  • H=16H=16H=16，每次预测 16 个动作；
  • w=8w=8w=8，实际先执行前 8 个动作，然后重新观察。

所以模型预测的不是当前画面要裁哪里，而是 8 个动作之后应该看哪里。下一次相机图像到来时，系统使用之前预测的 box，从新的原始图像中重新裁剪。

这种设计让动作和视觉关注形成时间上的配合：机器人正在把物体移动向目标时，模型可以提前把下一次视野切换到目标区域。

3. Foveation box 如何表示

每个 box 用四个坐标表示：

b=(ymin⁡,xmin⁡,ymax⁡,xmax⁡) b=(y_{\min},x_{\min},y_{\max},x_{\max}) b=(ymin​,xmin​,ymax​,xmax​)

每个坐标被量化为 1024 个离散 bin，因此一个 box 对应四个 location tokens。Single 视角输出一个 box，Dual 视角输出两个 box。

这些坐标由 PaliGemma 的 language-model head 自回归生成，不需要额外接 YOLO 或目标检测器。box 也不一定只包住一个物体，而是尽量覆盖当前 interaction region，例如夹爪、被操作物体和目标位置。

深度信息通过 Fast-FoundationStereo 恢复 metric depth，再做对数映射和伪彩色编码，送入共享视觉编码器。这样局部视觉不仅提供 RGB 细节，也提供物体和末端执行器之间的几何信息。

4. 训练：用交互标注监督关注区域

FoveaVLA 没有通过 RL 学习“看哪里”，也没有额外采集人类眼动数据。训练数据来自 DROID，作者利用 RoboInter 的 frame-level interaction annotations 生成 crop 监督。

不同 primitive skill 需要观察的内容不同：

技能 关注区域
Pick 夹爪 + 物体
Place / Transfer 夹爪 + 物体 + 目标区域
Fold / Insert 夹爪 + 操作对象 + 目标接触区域

将所需组件的 bounding box 求并集，再取最小外接矩形，并把它扩展成更大的方形 crop。默认边长约为原始 box 最大边长的 1.5 倍。训练中还会扰动裁剪中心和尺度，提高策略对定位误差的鲁棒性。

训练样本大致由标准 crop、扰动 crop 和完整视图组成。动作部分继续使用 Flow Matching，Foveation Head 使用自回归交叉熵：

L=Lflow+0.1Lfoveation \mathcal L=\mathcal L_{\text{flow}} +0.1\mathcal L_{\text{foveation}} L=Lflow​+0.1Lfoveation​

两个 loss 一起更新共享视觉语言 backbone。这里需要区分：模型学到的是由交互标注定义的合理观察区域，不是根据任务 reward 学出来的最优信息获取策略。

5. 实验结果

在真实 Franka Panda 任务中，作者比较了腕部相机基线、单外部视角和双外部视角：

方法 真实任务平均成功率
原始 π0.5\pi_{0.5}π0.5​（wrist camera） 52.1%
FoveaVLA-Single 70.8%
FoveaVLA-Dual 77.1%

普通抓放任务三种方法都能达到 100%，差异主要出现在干扰抓放、布料折叠和远距离移动等需要全局信息与局部细节同时存在的任务。

单外部视角在不使用腕部相机的情况下，比原始 wrist-camera 基线高 18.7 个百分点。作者的 attention analysis 也显示，原始策略容易集中在腕部视图，而 FoveaVLA 会同时利用外部全局视图和局部 crop。

消融更能解释提升来源：

  • 只增加 box supervision、不真正裁剪：约 31.3%；
  • 使用预测 box 生成 foveal crop：约 66.7%；
  • 外部完整 RGB-D、局部 RGB-D 和 foveation 结合：Single 达到 70.8%；
  • 只有外部 RGB-D、没有局部 crop：约 6.3%。

这说明提升主要来自真正把高分辨率局部视觉送回策略，而不是仅仅增加一个辅助定位 loss。Depth 也很重要，因为局部 RGB 本身不足以稳定替代腕部相机提供的几何关系。

作者还报告了 MolmoSpaces zero-shot 结果：FoveaVLA-Dual 为 22.4%，公开 π0.5\pi_{0.5}π0.5​-DROID 参考值为 17.8%，并在 9 个任务中的 7 个领先。但两个结果的相机布局、分辨率和深度条件并不完全一致，因此更适合作为初步泛化证据，而不是严格的受控比较。

6. 这篇论文真正说明了什么

FoveaVLA 的价值不只是“用一个 crop 替代 wrist camera”，而是把视觉输入选择接进了 action chunk 的闭环：

Perceptiont→(Actiont,Lookt+1)→Perceptiont+1 \text{Perception}_t \rightarrow (\text{Action}_t,\text{Look}_{t+1}) \rightarrow \text{Perception}_{t+1} Perceptiont​→(Actiont​,Lookt+1​)→Perceptiont+1​

这说明 VLA 的观察方式本身也可以成为策略输出的一部分。与固定相机或固定 crop 相比，动态 foveation 更接近机器人执行过程中的实际信息需求。

7. 局限和进一步方向

第一，当前方法不是真正基于 Value of Information 的主动感知。它学习的是 RoboInter 标注出的 interaction box，并没有直接优化某个区域对最终任务成功率的边际贡献。最合理的观察区域不一定总是物体位置，也可能是夹爪接触状态、失败后的异常区域或更大的全局范围。

第二，动作和 box 虽然共享 backbone，却没有显式建模 p(Bt+w∣At,ot)p(B_{t+w}\mid A_t,o_t)p(Bt+w​∣At​,ot​)。如果动作执行偏离预测轨迹，提前规划的 crop 可能与真实交互位置错开。

第三，一个 box 可能无法同时高质量覆盖相距很远的夹爪、源物体和目标。多 ROI、阶段化 crop，或者分别预测 grasp、transport、place 的观察区域，可能更适合复杂操作。

第四，真实实验每个任务只有 12 次试验，单次成败就约对应 8.3 个百分点；Single 使用 RGB-D，而 wrist-camera 基线的输入配置也不同。因此结果很有启发，但还不足以证明该方法在所有机器人和任务上都优于腕部相机。

更有潜力的方向，是让模型根据任务收益、失败风险和视觉计算成本选择观察方式：什么时候需要高分辨率 crop，什么时候需要更大视野，什么时候应该启用第二视角。结合失败恢复后，foveation 可以在正常执行时关注未来交互区域，检测到异常时重新观察接触点，再根据新的状态恢复动作。

8. 总结

FoveaVLA 把“下一步看哪里”变成了和“下一步怎么动”并行预测的动作。它证明了外部相机的全局视野、高分辨率局部视觉和深度几何信息可以组合起来，在一些任务中替代腕部相机。

它目前仍然是基于交互标注的监督式 foveation，而不是通过真实任务回报学习主动感知。但这已经提供了一个清楚的研究接口：下一步可以从预测合理的 Interaction Box，走向预测真正能够降低动作不确定性和失败风险的观察动作。
