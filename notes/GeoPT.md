# GeoPT：让廉价几何数据为物理仿真提供预训练信号

一辆车的 3D 模型相对容易获得，但计算它在某种来流条件下的压力和流速分布，可能需要昂贵的 CFD 求解。神经仿真器虽然推理快，训练时却仍然需要大量这样的求解结果。

GeoPT 的切入点是：**先在几何体周围构造廉价的合成运动，让模型学习方向、边界和空间位置之间的关系，再用物理仿真数据学习具体物理场。** 预训练不依赖真实物理标签，下游微调仍然需要。

论文：[GeoPT: Scaling Physics Simulation via Lifted Geometric Pre-Training](https://proceedings.mlr.press/v306/wu26s.html)，ICML 2026，MIT CSAIL 与清华大学合作；[项目主页](https://physics-scaling.github.io/GeoPT/)、[官方代码](https://github.com/Physics-Scaling/GeoPT)。本笔记依据提供的解读，并对照论文 v2 核查方法、数据配置和结果表格。

## 1. 为什么静态几何预训练未必能帮助物理预测

神经仿真器要学习的映射可以概括为：

\[
F_\theta(G,S,x)\rightarrow u(x).
\]

\(G\) 是几何，\(S\) 是边界条件、外部作用或材料等任务条件，\(x\) 是查询位置，\(u(x)\) 是压力、速度或应力等物理量。

静态几何任务只要求模型理解物体形状，例如预测一个点到表面的距离。对于同一辆车，正面来流和侧面来流不会改变它的静态距离场，却会改变周围的物理响应。

因此，缺少的是**运动条件如何与几何相互作用**。Vector Distance Field 本身具有几何方向信息，但没有指定外部来流或作用方向，不能将“向量距离有方向”与“表示已经包含动力学条件”混为一谈。

论文观察到，所测试的静态几何预训练可能没有收益，甚至出现负迁移。这不能推广为几何预训练对所有物理任务都没有意义；它说明预训练目标与下游任务之间需要更合适的联系。

## 2. 给几何体加上简单的合成运动

GeoPT 在几何体表面及周围空间采样查询点，并为点采样速度。其合成运动可以写为：

\[
\frac{d x_t}{dt}=v\,\mathbf 1_G(x_t),
\qquad x_0=x,
\qquad v\sim\operatorname{Unif}(\mathbb B^3).
\]

这里 \(\mathbb B^3\) 是有界速度球；\(\mathbf 1_G\) 按论文定义，在物体内部和边界取 0，在外部取 1。直观上，点沿采样方向移动，碰到几何边界就停止。

这不是流体绕过障碍物的真实运动，也没有模拟碰撞后的反弹、摩擦或形变。它只构造一种便宜、可计算、受几何边界约束的过程。

符号 \(V\) 表示各查询点速度的集合，不能默认所有点共享同一个全局速度。预训练让同一个几何体与多种合成运动配对，形成几何—运动条件空间。[合成运动定义](https://arxiv.org/html/2602.20399v2#S4)

## 3. 预测的是沿轨迹变化的几何特征

设 \(h_G(x)\) 是查询点到几何表面的向量距离特征。预训练输入几何、初始点和合成速度条件，输出沿运动轨迹的特征序列：

\[
F_\theta(G,x,V)\rightarrow
\bigl[h_G(x_0),h_G(x_1),\ldots,h_G(x_\tau)\bigr].
\]

对应的目标为：

\[
\mathcal L_{\mathrm{pre}}
=\mathbb E_{G,x,V}\left[
\left\|F_\theta(G,x,V)-h_G(x_{0:\tau})\right\|_2^2
\right].
\]

模型的监督标签仍然是几何特征，而不是实际流速、压力或应力。变化之处在于，模型必须根据运动方向和幅度，判断未来位置与几何边界的关系。

例如，两个初始距离相近的点，一个朝车身运动，另一个远离车身，未来的距离序列就不同。只记住初始静态距离已经不足以完成任务。

这就是 lifted 的含义：把只依赖几何的预训练，扩展到带运动条件的几何任务。新增的运动条件是人为构造的，但它使监督结构更接近下游“几何加作用条件决定响应”的形式。

## 4. 与输运方程有关，不等于已经学会完整物理规律

论文从带黏附边界的输运过程解释这种几何运动，并讨论它与守恒结构的联系。这个解释说明预训练任务具有物理相关结构，但不能直接推导出神经网络的下游输出一定严格守恒。

需要区分三个层次：合成过程本身的数学性质、网络是否准确拟合该过程，以及微调后的网络是否满足目标物理系统的方程和边界条件。

同样，“遇到表面就停止”可以帮助模型学习边界相关信息，却没有提供黏性、湍流、材料本构或接触摩擦的完整规律。这些仍需要来自下游数据及任务设计。

## 5. 从几何预训练转到物理场预测

GeoPT 主要使用 Transolver 骨干。微调时，将随机速度条件换成编码真实任务设置的 \(V_S\)，并将监督目标换成求解器生成的物理场。

| 下游任务 | 条件如何组织 | 预测目标示例 |
| --- | --- | --- |
| 汽车、飞机空气动力学 | 来流速度、攻角或侧滑方向 | 表面压力、周围流速 |
| 船舶水动力学 | 水相与空气相的运动条件 | 船体压力、水流状态 |
| 汽车碰撞 | 碰撞位置、方向及空间变化的作用条件 | von Mises 应力 |

这里的 “prompt” 是数值条件场，不是自然语言，也不是把几何模型输入后就零样本完成所有仿真任务。不同物理任务仍需设置条件编码、输出和微调监督。

概念上可以写成拟合 \(F_\theta(G,x,V_S)\) 与 \(u(x)\) 的误差。具体训练还涉及归一化：原文实验配置列出的微调损失是 Relative L2，不能把概念性的平方误差表达直接当成完整复现配方。

官方仓库也强调几何对齐。若模型预训练时使用归一化坐标，下游几何和条件必须采用一致约定；不能随意缩放物体后仍把物理尺度当作未改变。[适配说明](https://github.com/Physics-Scaling/GeoPT)

## 6. 一百多万个样本，不是一百多万个独立物体

预训练使用 ShapeNet 中的汽车、飞机和船舶几何。原文配置列出的独立几何数为：

\[
7{,}479+4{,}045+1{,}939=13{,}463.
\]

每个几何配 100 组运动条件，得到 1,346,300 个样本。每个样本包含 32,768 个体积点与 4,096 个表面点。运动步数 \(\tau=2\)，连同初始状态共有三个时间点。[数据配置表](https://arxiv.org/html/2602.20399v2#A5)

提供的解读记录了约 5 TB 的预计算数据，以及使用 80 个 CPU 核约三天生成的成本。这是监督数据生成成本，不包含全部神经网络预训练开销，也不等于在普通电脑上三天完成整个方法。

一个重要实验观察是，扩大独立几何的多样性比只为同一批几何增加更多随机运动更有帮助。对于预训练数据设计，这提醒我们区分新形状带来的覆盖与重复采样带来的数量增长。

## 7. 实验收益怎样理解

五个主要工业级基准是 DrivAerML、NASA-CRM、AirCraft、DTCHull 和 Car-Crash。8 层骨干的部分 Relative L2 Error 如下，越低越好：

| 基准 | 从头训练 Transolver | GeoPT 预训练后微调 |
| --- | ---: | ---: |
| DrivAerML | 0.0927 | 0.0746 |
| AirCraft | 0.1104 | 0.0904 |
| DTCHull | 0.1814 | 0.1459 |

这些数字对应论文附录 Table 6，同骨干设置下比较预训练与从头训练；它们是物理场预测误差，不是机器人任务成功率。[结果表](https://arxiv.org/html/2602.20399v2#A6)

论文概括的 20%–60% 标注数据节省，指在相应任务和目标精度下减少下游物理样本；约 2× 收敛收益，指相应下游学习曲线的改善。二者都不是对任意新任务的保证，也不代表包含预训练、数据生成和部署在内的总成本都减半。[论文摘要](https://proceedings.mlr.press/v306/wu26s.html)

更大的模型与更多几何数据带来继续改善，是积极的 scaling 证据，但目前仍应限定在测试范围内。要判断总成本是否合算，还要看预训练模型能被多少下游任务复用。

## 8. 它与机器人 World Model 的距离在哪里

GeoPT 的主实验主要预测稳态或汇总物理场，附录也扩展到非稳态水动力学。Car-Crash 使用的是每个单元在碰撞轨迹中达到的最大 von Mises 应力，因此不能把这一结果描述为模型已经生成了完整碰撞演化过程。

机器人 World Model 还需要处理动作执行器、物体身份、接触模式切换、摩擦、遮挡和长时间误差累积。工业物理场上的迁移收益，不足以证明这些能力已经具备。

不过，它提供了一个值得借鉴的任务设计原则：**如果下游需要动作条件，就不要只让预训练学习静态物体，而应让廉价监督也依赖某种动作或运动条件。**

例如，可以从 Mesh 和随机末端运动构造接触位置、首次碰撞时间、扫掠路径是否受阻等标签。这些首先属于几何交互监督，不能仅凭 Mesh 推出摩擦力或材料形变。进一步学习接触动力学，仍需要相应物理参数与监督。

一个有辨识力的后续实验，是固定下游机器人数据，比较随机初始化、静态距离场预训练、运动条件下的几何预训练。除预测误差外，再检验插入成功率、碰撞恢复和未见形状泛化。这是受 GeoPT 启发的研究方向，不是论文已完成的机器人验证。
