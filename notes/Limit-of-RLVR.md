# Limit of RLVR 论文解读：成功率提高，是否意味着能力边界扩大

**论文：** Does Reinforcement Learning Really Incentivize Reasoning Capacity in LLMs Beyond the Base Model?  
**作者与团队：** 乐洋（Yang Yue）、Zhiqi Chen 等，清华 LeapLab 等  
**发表：** NeurIPS 2025；[Best Paper Runner-up](https://blog.neurips.cc/2025/11/26/announcing-the-neurips-2025-best-paper-awards/)  
**资源：** [论文](https://arxiv.org/abs/2504.13837) · [PDF](https://arxiv.org/pdf/2504.13837) · [项目主页](https://limit-of-rlvr.github.io/) · [会议收录](https://proceedings.neurips.cc/paper_files/paper/2025/hash/537d5aa768c2d534016a4d06f87bc8fb-Abstract-Conference.html)

**一句话概括：这篇论文把 RLVR 带来的单次成功率提升，与有限采样预算下可解题集合的扩大区分开来，并发现两者在所研究的训练设置中可能朝不同方向变化。**

它最有价值的贡献是一套评价视角：除了问模型“这次能否做对”，还要问“多给一些尝试，它究竟能覆盖哪些问题”。[来源：论文](https://arxiv.org/abs/2504.13837)

## 一、研究问题：采样效率与能力覆盖是两件事

假设一个 Base Model 对某道题存在两条路径：错误路径 A 的采样概率为 99%，正确路径 B 为 1%。经过 RLVR 后，正确路径 B 的概率提高到 80%。

单次准确率因此大幅提高，但正确路径在训练前已经存在。这说明模型更容易采样到已有正确解，尚不能说明它获得了原本在给定预算下无法达到的新解法。

论文据此区分：

- **Sampling Efficiency：** 以更少尝试找到正确答案的能力。
- **Reasoning Capacity 的经验边界：** 在约定采样预算和评测协议下，可以覆盖多少问题。

## 二、核心方法：同时看 pass@1 和大 k 的 pass@k

对于一道题，若每次独立采样的正确概率为 $p$，至少一次成功的概率为：

$$
\operatorname{pass@}k = 1-(1-p)^k.
$$

对整个数据集，需要对各题不同的 $p_i$ 分别计算，再求平均；不能直接把数据集平均正确率代入上式。

论文实际还使用有限样本下的低方差估计：生成 $n$ 个答案，其中 $c$ 个正确，则在 $n\geq k$ 时：

$$
\widehat{\operatorname{pass@}k}
=1-\frac{\binom{n-c}{k}}{\binom{n}{k}}.
$$

这与“每题采样 16 次后计算所有回答的平均正确率”不同；后者仍是在估计单次回答的准确率。[来源：论文第 2 节与附录 A.2](https://arxiv.org/html/2504.13837v4)

### 一组帮助理解的示意数据

| 尝试数 k | Base Model | RLVR Model |
| ---: | ---: | ---: |
| 1 | 10% | 30% |
| 4 | 22% | 45% |
| 16 | 42% | 59% |
| 64 | 67% | 66% |
| 256 | 81% | 70% |
| 1,024 | 88% | 72% |

**以上来自来稿的说明性示意，不是论文实测数据，也不是把一个固定 p 代入公式得到的单题曲线。** 它展示了不同题目上的成功概率发生变化后，数据集平均 pass@k 曲线可能交叉的情形。

## 三、论文证据：单次准确率与覆盖范围如何分离

### 1. 训练过程中的 pass@k 变化

以 Qwen2.5-7B 在 Omni-MATH 训练集上的实验为例：

| 模型状态 | pass@1 | pass@256 |
| --- | ---: | ---: |
| Base Model | 9.9% | 67.2% |
| GRPO，450 步 | 42.5% | 64.3% |

这一结果说明，同一训练过程中，模型更容易一次答对，与它在多次尝试中覆盖更多问题，并不必然同时发生。这里是训练集上的诊断结果；论文另有测试集和数学、代码、视觉推理实验。[来源：论文附录 Table 4](https://arxiv.org/html/2504.13837v4)

### 2. 哪些题只有其中一个模型能解出

在 AIME 2024 的一组最多 1,024 次采样实验中：

| 可解题集合 | 占比 |
| --- | ---: |
| 两者都至少答对一次 | 63.3% |
| 只有 Base Model 答对 | 13.3% |
| 只有 RLVR Model 答对 | 0.0% |

这个实验比单个平均分更直接地观察了解题集合。作者还计算 Base Model 对 RLVR 推理轨迹的 perplexity，发现这些轨迹通常也能获得较高似然。集合分析与轨迹似然共同支持：在这些设置中，RLVR 的主要效果是重新分配已有推理路径的采样概率。[来源：论文覆盖分析与附录](https://arxiv.org/html/2504.13837v4)

## 四、为什么蒸馏可能表现不同

RLVR 主要依靠模型自行生成候选解法，再用可验证的结果奖励更新策略。蒸馏则直接引入 Teacher 的推理轨迹，让 Student 接触自身难以独立采样到的解法。

论文观察到，蒸馏模型的 pass@k 曲线可以超过 Base Model。这一对照强调了**训练信息来源**的作用：是否提供了新的轨迹、分解方式或解题策略，会影响能力覆盖范围如何变化。[来源：论文第 4.2 节](https://arxiv.org/html/2504.13837v4)

## 五、如何准确理解结论

论文支持的经验性结论是：在其研究的、主要使用自身 rollout 与结果奖励的 RLVR 设置中，训练显著改善了采样效率，但不保证扩大有限预算下的可解题范围，部分设置还出现覆盖收缩。

这不是“任何 RL 都无法产生新能力”的数学定理。模型的理论分布支持集，与现实预算内能有效找到的解，属于不同层面。softmax 可以为大量序列分配非零概率，但极低概率轨迹在实际计算中可能无法触达。

对照阅读 [ProRL](ProRL.md) 和 [Curriculum RL](Curriculum-RL.md) 更有帮助：前者研究长时间训练与探索控制，后者引入针对能力边界的教师信息。它们改变了训练条件，使“何时能够扩大能力覆盖”成为可以继续实验的问题。

## 六、对 RoboDojo 与 Self-Improving Agent 的启发

以下是由论文评价方法延伸出的研究建议。

如果一个机器人 Agent 原本能在多次尝试中解决 100 个固定布局中的 60 个，改进后只是在这 60 个布局上成功得更频繁，那么主要收益是可靠性或采样效率。若在相同预算下开始解决此前始终失败的新布局，则提供了有效能力覆盖扩大的证据。

建议同时记录 Success@1、固定预算下的 Success@k、改进前后可解布局集合及其新增与丢失部分。k 应表示独立执行尝试，并另行记录每次尝试内部的工具交互和代码修改次数。

机器人还能通过环境交互获得新的物理信息，并修改技能库或控制程序，因此需要把模型参数、外部记忆、技能资产和环境反馈分别计入系统配置。这样才能解释能力变化来自哪里。

这篇论文留下的核心问题是：**训练让模型更稳定地使用已有解法，还是让系统在相同预算下真正解决了新的实例？**
