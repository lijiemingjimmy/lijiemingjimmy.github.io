RAFT：VLA 微调时，怎样保住任务相关的理解能力？

论文：RAFT: Reasoning-Aligned Fine-Tuning Improves Robustness of VLA Post-Training
作者：Shresth Grover、Andrey Kolobov、Dhruv Shah；Princeton / Microsoft Research。2026 年 11 月 3 日提交。
资料：原文 HTML · 项目主页 · 代码入口

这篇文章关心一个很实际的问题：模型在固定桌面上越训越熟，为什么换个背景、换种颜色，反而不会做了？

RAFT 的处理方式是先用任务相关的视觉与空间标注训练一个 LoRA，再冻结这个 LoRA，用示范训练动作。它希望让少量动作数据适配机器人的同时，保留一部分对目标物体、位置关系和运动路径的关注。

下面根据提供的解读整理，并对照 v1 原文核对关键结论。研究建议与公式中的解释性简化会单独说明。

1. 微调到底可能把什么学偏？

假设机器人需要把杯子放进盒子，50 条示范里杯子总在左侧，盒子总在右侧，桌面纹理也几乎不变。

要拟合这些示范，模型可以学会识别杯子和盒子，再根据相对位置行动；也可以主要记住某些图像特征出现时应该输出哪段动作。在这些训练样本上，两种办法都可能得到很低的动作误差。

区别要到环境变化后才显现：换一张桌布，第一种策略仍然能找到杯子，第二种策略依赖的视觉关联却可能失效。

用一个简化的表示来理解：

o=(z,b),a=f(z,l). o=(z,b),\qquad a=f(z,l). o=(z,b),a=f(z,l).

这里 zzz 是任务相关状态，例如目标位置、夹爪位置；bbb 是背景等非必要因素；lll 是指令。真实任务主要依赖 zzz，但在有限示范中，bbb 也可能与动作高度相关。仅凭动作监督，模型未必能分清两者。

这至少涉及三件事：数据没有覆盖足够多的变化，模型使用了容易拟合的视觉捷径，以及微调改变了预训练表征。它们可以同时发生。因此，“微调后更脆”值得研究，但将所有失败都归结为灾难性遗忘，会把问题说得过窄。

RAFT 的切入点是增加一层监督：让模型在学动作前，先明确当前任务应该关注哪些信息。

2. Reasoning 在这里具体是什么？

看到 Reasoning 很容易想到长篇思维链。RAFT 使用的监督相当具体：目标对象、物体框、抓取点、目标点、空间描述，以及图像平面中的运动轨迹。

例如“把杯子放进碗里”，监督可以包含：

监督形式 想让模型表达的信息
物体描述 / VQA 应当操作哪个杯子，放进哪个容器
Bounding box 杯子与碗分别位于图像哪里
Keypoints 抓取位置、抬升位置和放置位置
Spatial description 杯子在碗左侧，夹爪需要先靠近杯子
Trajectory trace 图像中从当前位置到抓取点、再到目标的路径

标注由 Gemini 3.1 Pro 生成，随后序列化成 token，让模型学习生成这些目标。方法与标注格式

这些标注的作用可以理解为给视觉表征加上任务约束：模型不能只记一个动作结果，还要表达与动作有关的对象和空间关系。

这里的二维轨迹提供的是视觉上的运动提示。把它转成真实机械臂动作，还需要处理深度、运动学、碰撞和接触。RAFT 的动作学习阶段承担后续适配。

3. 两个训练阶段怎么接起来？

第一阶段：用推理监督训练 LoRA

设预训练模型参数为 θ0\theta_0θ0​，LoRA 参数为 ϕ\phiϕ，推理目标序列为 rrr。第一阶段可以写成：

ϕ∗=arg⁡min⁡ϕ−E(o,l,r)∑jlog⁡pθ0,ϕ(rj∣o,l,r<j). \phi^*=\arg\min_\phi -\mathbb E_{(o,l,r)} \sum_j\log p_{\theta_0,\phi}(r_j\mid o,l,r_{<j}). ϕ∗=argϕmin​−E(o,l,r)​j∑​logpθ0​,ϕ​(rj​∣o,l,r<j​).

预训练主体固定，只更新 LoRA。训练目标是让模型更好地表达当前任务所需的对象、位置和路径信息。

第二阶段：冻结 LoRA，适配动作

保留 ϕ∗\phi^*ϕ∗，随后用机器人示范更新动作策略中的可训练参数 θ\thetaθ：

θ∗=arg⁡min⁡θE(o,l,a)∼Dℓaction(θ,ϕ∗;o,l,a). \theta^*=\arg\min_\theta \mathbb E_{(o,l,a)\sim\mathcal D} \ell_{\mathrm{action}}(\theta,\phi^*;o,l,a). θ∗=argθmin​E(o,l,a)∼D​ℓaction​(θ,ϕ∗;o,l,a).

这里用通用的 ℓaction\ell_{\mathrm{action}}ℓaction​，因为具体目标取决于底层策略的动作表示和训练方式。对于 flow-based action expert，直接写成离散动作 token 的交叉熵会造成误解。

部署时，训练好的适配器继续参与模型计算，策略直接预测动作。它的主要收益来自训练时的表征约束，不能据此假定执行每个动作前都会生成一段可读推理。

4. 为什么“冻结推理 LoRA”不等于“推理能力永远不变”？

这是理解这篇文章最值得停下来想的一步。

用一个简化的 LoRA 线性层表示：

h′=(Wθ+ΔWϕ∗)h. h'=(W_\theta+\Delta W_{\phi^*})h. h′=(Wθ​+ΔWϕ∗​)h.

虽然 ΔWϕ∗\Delta W_{\phi^*}ΔWϕ∗​ 被固定，第二阶段仍可能更新 WθW_\thetaWθ​，上游产生的 hhh 也可能变化。整个层的输入输出关系当然还会变。

冻结所提供的直接保证是：动作梯度不会修改这组 LoRA 参数。它给后续优化保留了一个由推理监督学出的固定组成部分；最终是否保住了任务相关能力，仍要通过行为实验和表征分析检验。

这个区别也解释了为什么 RAFT 可以有效，却不构成“彻底解决遗忘”的数学保证。固定一个参数子集，与固定一个完整功能，是两种不同约束。

5. 实验效果：最强证据来自哪里？

DROID：训练场景差不多，环境变化后差距很大

MolmoBot 使用 50 条抓取放置示范后，结果为：

评测范围 Plain FT RAFT
ID，原始训练场景 约 60% 约 63%
OOD，颜色 / 干扰物 / 背景变化合并 27.9% 75.0%

OOD 共 68 次测试：对象变化 24 次、干扰物 24 次、背景变化 20 次。因此 75.0% 是这些测试合并的结果，不应理解成每一种变化都达到 75%。真机实验及评测协议

从提供的结果可以算出，OOD 提升约 47.1 个百分点，远大于 ID 的约 3 个百分点。对这项任务而言，RAFT 的主要价值体现在环境变化后的稳定性。

这个现象也说明，只比较原始场景的成功率，会漏掉后训练方法的重要差别。

YAM：看完整双臂流程是否完成

YAM 使用 π0.5\pi_{0.5}π0.5​ 和 100 条示范。一只手打开并保持盒盖，另一只手抓取物体并放入盒子。RAFT 完整任务平均成功率为 70%，最强对照 DeLock 为 36%。

这里的平均包含 ID 和多类 OOD 条件，统计范围与 DROID 的纯 OOD 合并结果不同。两项结果应分别理解。

对这种任务，单独记录“盒盖打开了没有”还不够。保持盒盖、抓取、转移和放置都可能出错，完整任务成功率才反映整段行为是否衔接起来。真机结果

仿真：提升更温和，也更容易拆解原因

Pick-and-place 五类测试平均成功率为 83.21% 对 79.62%；OOD-object 为 43.40% 对 35.85%。

平均提升约 3.6 个百分点，同时新物体成功率仍低于一半。这意味着 RAFT 的收益与任务、基础模型和扰动类型有关，真机上的大幅提升不能直接当成所有场景的预期收益。

6. 消融比一句“先理解再行动”更有信息量

下表整理同一仿真抓取放置设置中的结果，平均包含 ID、光照、纹理、物体和指令五类测试。

训练方式 平均成功率
推理与动作联合训练 63.21%
先推理后动作，第二阶段继续更新 LoRA 73.96%
普通动作微调 79.62%
普通动作微调，冻结视觉编码器 79.62%
RAFT：先推理，冻结 LoRA，再学动作 83.21%

来源：附录消融。

第一，增加推理标签本身不保证收益。 联合训练在这里表现较差，说明监督如何组织、更新哪些参数，同样会影响结果。联合训练的失败仍然只对应作者测试的配方，无法排除其他损失配比和调度方式。

第二，保护视觉编码器可以解释一部分收益。 在 OOD-object 上，冻结视觉编码器的普通 FT 达到 40.57%，RAFT 为 43.40%。两者相差约 2.8 个百分点，比 RAFT 相对原始 Plain FT 的差距更小。解释收益时，需要把视觉冻结和推理监督两项设计分开。

第三，监督形式应当由任务决定。 OOD-object 上，轨迹监督达到 45.28%，完整推理为 43.40%。这支持优先比较哪些信息有用，而不是直接把完整标注当作最优选择。差距较小时，还需要结合试验数量和训练波动判断稳定性。

我更关心的后续问题是：如果只标关键点、只标对象关系，就能取得接近的效果，是否可以省掉复杂标注的生成和清洗成本？这需要等预算实验，现有结果只提供了方向。

7. 表征分析支持什么？

论文观察到 RAFT 更关注目标、夹爪等区域，物体身份也更容易从中后层特征中线性解码。提供的解读中，物体身份 Balanced Accuracy 约为 0.51–0.53，普通 FT 约为 0.45。

这与“保留了更多任务相关信息”的解释一致。不过，一个信息能被探针读出来，还需要进一步证明策略实际使用它来控制动作。注意力集中在物体上，也不能独立证明这一区域对决策有因果作用。

附录还有两个会影响解读的细节：所谓进度标签是轨迹时间四等分；探针留出的是探针训练中的 episode，这些 episode 曾参与策略训练。因此该分析衡量的是特征可解码性，不能直接当成未见任务阶段理解的证据。探针协议

一个可以补充的实验是：固定画面和物体布局，只改变语言指定的目标。如果模型随指令改变抓取对象，而且这种能力在动作微调后仍然保持，就能更直接地检验任务语义是否影响行为。

还可以遮挡目标、遮挡背景，比较动作变化是否符合预期。上述实验是进一步验证机制的建议。

8. 和 WAM、灵巧操作有什么关系？

与 WAM 训练的共同问题

在 WAM 训练参考：VPP2 中，一个重要问题是：接入动作学习后，视频基座原有的指令跟随和泛化能力还能保留多少？

RAFT 也在处理“基础能力向控制能力迁移时，哪些信息应该被保留”。两条路线监督的内容不同：这里是对象、空间和视觉轨迹；WAM 还可能涉及未来视频与交互变化。可以借鉴的是分别评测基础能力和动作能力，再检查训练顺序与参数更新如何影响两者。

例如，动作成功率提高的同时，目标识别或视频指令跟随下降，这个模型的适用范围可能变窄了。只看一个总成功率，很难发现这件事。

对接触密集操作的延伸

若面向灵巧手，值得尝试的监督包括接触位置、接触状态、预期滑移方向和相对运动。这些是研究假设，RAFT 本身没有证明它们有效。

首先要解决标签来源。二维框和接触力的观测条件不同，单张 RGB 通常无法确定摩擦、法向力或接触是否稳定。比较可靠的设计应区分：图像可观察的几何线索、需要多帧估计的状态，以及需要触觉或仿真才能获得的物理量。

其次要把评测变化分开。换背景主要考验视觉鲁棒性；换物体几何会改变抓取与可达性；换摩擦系数则可能要求不同的力或速度。它们都属于分布变化，但失败原因和需要的监督不一样。

9. 如果沿着这篇文章做研究，我会先补哪些对照？

问题 可以做的对照 能澄清什么
收益来自额外训练时间吗？ 匹配总训练算力和动作数据量 训练预算与监督设计的贡献
冻结什么最有效？ 冻结视觉、冻结不同层、冻结推理适配器 参数保护的位置是否关键
标签的语义内容有用吗？ 正确标注与保持格式但错配内容的标注 收益是否依赖任务相关信息
同时训练还有改进空间吗？ 扫描损失权重和采样比例 当前联合训练配方是否充分优化
能否保持语言控制？ 同一场景切换目标指令 策略是否仍根据指令选择对象
推广到接触变化有效吗？ 分开改变几何、质量、摩擦 视觉收益能否延伸到物理适配

这些实验中，训练预算、演示数据和测试任务应保持可比。尤其不能让一种方法额外看到目标测试场景的标注，再把差距全部归因于参数冻结。

RAFT 给我的主要启发是：后训练需要同时考虑学会新任务与保留可迁移信息。 任务相关监督、训练顺序和参数冻结共同影响这件事。它提供了一个容易解释、值得作为基线验证的配方；真正值得继续追问的是，哪些信息需要保护，以及保护后是否确实改善了目标分布之外的行动。
