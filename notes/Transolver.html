Transolver：把大量网格点变成少量物理状态，再做 Attention

Transolver 研究的是一个很具体的问题：物理仿真有大量空间采样点，但模型是否必须让每两个点都直接计算一次 Attention？

它提出先把点的特征聚合成少量可学习的 physics-aware tokens，在这些 token 之间交换信息，再把结果还原到每个点。这样既保留逐点预测接口，又降低全局交互的计算成本。

论文：Transolver: A Fast Transformer Solver for PDEs on General Geometries，ICML 2024。作者为 Haixu Wu、Huakun Luo、Haowen Wang、Jianmin Wang 和 Mingsheng Long。正式论文｜arXiv｜官方代码

1. 为什么物理仿真需要这种架构？

以汽车空气动力学为例，输入可以包括车身几何、空间位置、来流条件；输出则是车身表面压力或周围的流场。传统数值求解器把空间离散成网格，再求解物理方程。神经求解器希望从已有仿真数据中学习这种映射，训练完成后，用网络前向预测近似解。

这里的难点是，网格点很多，而且几何形状并不规则。直接把每个点当成一个 token，标准全局 Attention 的交互开销随点数平方增长。

另一方面，点数多并不意味着存在同样多种独立的物理状态。例如流动中的某些区域可能具有相近的响应模式。若能学习一种更紧凑的表示，模型就不必在原始点集合上完成所有全局交互。

Transolver 的出发点，就是把“物理场有多少采样点”和“全局交互需要多少个 token”分开。

2. Physics-Attention 到底怎么做？

可以把一个模块理解为：

逐点特征 → 学习分组权重 → 聚合成 slice tokens → token 间 Attention → 分发回每个点。

下面用单个 Attention head 的简化记号说明，省略批次维度。设有 NNN 个点，第 iii 个点当前的隐特征为 xix_ixi​，希望聚合出 MMM 个 slice，通常 M≪NM\ll NM≪N。

先学习每个点如何参与不同的 slice

模型根据点特征产生分配权重：

wij=softmax⁡j(g(xi)/T),∑j=1Mwij=1. w_{ij}= \operatorname{softmax}_{j}\bigl(g(x_i)/T\bigr), \qquad \sum_{j=1}^{M}w_{ij}=1. wij​=softmaxj​(g(xi​)/T),j=1∑M​wij​=1.

这里的 softmax 沿 slice 维度计算。wijw_{ij}wij​ 表示第 iii 个点对第 jjj 个 slice 的参与程度，TTT 控制分配的尖锐程度。

这是一种软分组：一个点可以同时参与多个 slice；空间上不相邻的点也可以进入同一个 slice。分组来自网络特征，不需要提前给出“这个点属于尾流区”之类的标签。

把点聚合成少量 token

对点特征做投影，再按分组权重求加权平均：

zj=∑i=1Nwijf(xi)∑i=1Nwij+ε. z_j= \frac{\sum_{i=1}^{N}w_{ij}f(x_i)} {\sum_{i=1}^{N}w_{ij}+\varepsilon}. zj​=∑i=1N​wij​+ε∑i=1N​wij​f(xi​)​.

现在，原来的 NNN 个点被汇总成了 MMM 个 token。分母用于归一化，避免一个 slice 仅仅因为汇集了更多点，就得到更大的特征幅值。

可以把每个 token 理解成网络从当前特征中提取的一类状态摘要。它是否对应某种清晰的物理现象，需要结合可视化和实验判断。

在 token 之间交换信息，再还原到点

对这些 token 做标准 Attention：

Z′=softmax⁡(QK⊤d)V,Q=ZWQ, K=ZWK, V=ZWV. Z'=\operatorname{softmax} \left(\frac{QK^\top}{\sqrt{d}}\right)V, \qquad Q=ZW_Q,\ K=ZW_K,\ V=ZW_V. Z′=softmax(d​QK⊤​)V,Q=ZWQ​, K=ZWK​, V=ZWV​.

然后利用此前的分组权重，把更新后的信息分发回原始点：

yi=∑j=1Mwijzj′. y_i=\sum_{j=1}^{M}w_{ij}z'_j. yi​=j=1∑M​wij​zj′​.

这样，每个点都可以通过少量中间 token 获得全局信息。上面是说明机制的简化写法；官方实现还包含多头、不同的输入投影和输出投影。Physics-Attention 实现

3. “物理状态”应该怎么理解？

论文用 physics-aware 来描述这些 token，强调分组可以随着预测任务学习，而不局限于固定的空间划块。

但不能因此把每个 slice 都理解成一个有明确名称的物理区域。比如模型可能学出与尾流、边界或材料响应有关的分组，也可能形成较难直接解释的潜在表示。

还要避免一个误解：模型预测压力时，并不需要先知道真实压力，再按压力把点分组。 它从可用输入及逐层更新的隐特征中产生权重，整个过程由训练目标驱动。

因此，这里的“物理状态”更适合理解为有利于物理预测的任务相关表示。学习到这种表示，与显式识别守恒量、严格满足物理方程，是不同层面的能力。

4. 为什么能降低复杂度？

忽略特征宽度、头数等因素时，标准全局 Attention 的交互开销为：

O(N2). O(N^2). O(N2).

Physics-Attention 的点与 slice 之间聚合、还原约为 O(NM)O(NM)O(NM)，slice 之间交互约为 O(M2)O(M^2)O(M2)，合起来是：

O(NM+M2). O(NM+M^2). O(NM+M2).

当 MMM 固定时，这部分计算随点数 NNN 线性增长。

例如，若有 10 万个点、64 个 slice，直接点间 Attention 对应约 100 亿个配对位置；点与 slice 的权重矩阵则约有 640 万个位置。这只是结构规模的示意，不能直接换算成同等比例的实际加速。

完整网络还要保存点特征、计算线性投影和前馈网络，也有反向传播与数据搬运成本。线性复杂度仍然会随着点数增长，不能据此认为任意规模的几何都能轻松放进显存。

这里也存在表达能力的取舍：slice 太少可能压缩掉重要细节，增加 slice 又会提高计算成本。对于细薄边界、局部突变或接触区域，尤其需要检查全局平均误差之外的局部预测质量。

5. 实验结果说明了什么？

论文报告在六个标准 PDE 基准上，相对既有最佳方法取得约 22% 的误差下降，并展示了汽车与翼型相关的工程预测结果。论文摘要与正式出版信息

这个数字支持的是：在作者测试的数据集、训练设置和评价指标下，所提出的架构有优势。它不是“所有物理问题都提升 22%”，也不是相对传统数值求解器的统一精度提升。

阅读这类结果时，可以分别看三个问题：

  • 预测精度： 哪些物理量改善了，局部极值、边界附近是否也准确？
  • 计算效率： 在相近误差水平下，推理时间与显存如何变化？
  • 泛化能力： 更换几何、网格密度或物理条件后，误差是否仍然可控？

支持不规则点集输入，解决的是架构的适用性；新几何上的预测是否可靠，还取决于训练数据与测试分布。

此外，神经求解器的快速推理依赖前期数据生成和训练投入。对于需要反复评估大量设计的任务，这种投入可能有价值；对于一个全新的、只求解一次的问题，则需要重新计算成本。

6. 和 GeoPT 放在一起，就更容易理解

GeoPT 与 Transolver 处理的是同一条研究链条上的不同问题。

工作 主要问题 方法重点
Transolver 大量几何点之间如何高效交换信息？ 聚合出少量 slice tokens，再计算全局交互
GeoPT 真实仿真标签昂贵，预训练信号从哪里来？ 用几何体与合成运动构造物理相关的监督

可以把 Transolver 看作神经仿真器的一种骨干架构，把 GeoPT 看作训练这种模型的一种预训练思路。GeoPT 使用 Transolver，并不意味着 Physics-Attention 本身就不需要物理数据；下游精确预测仍然需要对应任务的监督与验证。

这也提示了两个可以独立研究的方向：固定数据比较架构，判断表示和计算方式是否更好；固定架构比较预训练任务，判断廉价监督是否帮助模型更快学到真实物理规律。

7. 对机器人和 World Model 有什么启发？

下面是从架构出发的研究设想，不是原论文已经验证的机器人能力。

机器人操作同样面对大量局部观测：物体点云、手指表面、触觉阵列、接触附近的几何。真正影响下一步运动的因素，可能集中在少量接触关系与受力模式上。

因此可以尝试：先把局部观测聚合成少量交互 token，让这些 token 结合动作条件交换信息，再预测接触变化、物体运动或局部形变。

但操作任务有一个特别值得警惕的问题：接触点可能只占很小一部分空间，却决定了任务成败。普通加权聚合是否会把它们稀释掉，需要实际验证。一个合理的实验，是比较普通软聚合与保留接触局部信息的聚合方式，在滑动、插入、抓持变化等任务上是否存在差异。

如果目标是动作条件世界模型，还必须明确输入当前状态与动作，预测未来状态，并评估多步误差。单次物理场预测的成功，不能直接替代长时序闭环实验。

8. 后续版本应该分开看

Transolver++ 和 Transolver-3 延续了这一方向，但它们的规模与优化结果属于各自后续工作，不能全部归到 2024 年的原始模型上。

  • Transolver++，ICML 2025：面向百万点规模几何的神经 PDE 求解。
  • Transolver-3，ICML 2026：面向上亿单元的工业几何，进一步优化 slice/deslice 计算与分块处理。

对原始 Transolver 最值得记住的是这个架构选择：保留高分辨率的逐点输入与输出，把昂贵的全局交互放到少量学习出来的 token 上。 它给出了一个有用的压缩方式，而这种压缩能否保留具体任务所需的物理细节，仍然是后续模型设计和实验的核心。
