Research notebook · 研究笔记

UNITAS：在三维空间中统一动作与世界变化

论文：A 3D-Native World Action Model for Embodied Manipulation。

本笔记依据提供的论文解读整理，实验数字沿用该材料，未独立复核原文。

UNITAS 的出发点是：机器人在三维物理空间中操作，但视频世界模型往往在二维图像空间中描述变化。相同的真实位移，在不同相机视角下可能表现为完全不同的像素运动。

它选择用 具有物理尺度的三维点轨迹 同时表示机器人运动与环境变化，让动作和场景动态共享一种表示形式。

1. Action Flow 与 Scene Flow

UNITAS 将三维运动分成两类：

表示 描述什么
Action Flow 夹爪或人手上的点如何运动
Scene Flow 环境中的物体和场景点如何运动

例如机器人把杯子向右推，Action Flow 描述夹爪轨迹，Scene Flow 描述杯子及其他场景点随之发生的变化。材料中提到，每个机器人夹爪可采样 20 个点来表示其运动。

这使模型既可以描述操作本身，也可以在给定 Action Flow 后预测场景后果。

这里的 Flow 指三维点的运动，不应和生成模型中从噪声到样本的 Flow Matching 速度场混为一谈。

2. 每个点用一个轨迹 token 表示

对当前三维点 xt,nx_{t,n}xt,n​，未来位移写成：

Δxn,k=xt+τk,n−xt,n. \Delta x_{n,k}=x_{t+\tau_k,n}-x_{t,n}. Δxn,k​=xt+τk​,n​−xt,n​.

模型预测的是同一个点在不同未来时刻的位移，而不是每一帧重新生成一套没有对应关系的点云。

UNITAS 使用 Physical-Time Trajectory Tokenizer，将一个点在多个时刻的位移编码成一个 latent token。这样，序列中的 token 数量主要随点数变化，而不必直接等于“点数 × 时间步数”。

另一个关键是使用真实物理时间 τk\tau_kτk​，而不是只记录帧序号。10Hz 与 20Hz 的数据中，相隔一帧代表不同持续时间；使用物理时间可以帮助模型处理不同采样频率的轨迹。

这种表示有利于混合机器人和人手数据，但时间统一不意味着不同本体的动作已经完全等价。几何标定、点对应关系和执行器约束仍然需要处理。

3. 让视觉特征也对齐到世界坐标

只把输出写成三维轨迹还不够，输入视觉特征也需要知道自己对应哪个物理位置。

有深度时，UNITAS 使用相机内参、外参和深度，把像素反投影到世界坐标，再给视觉 token 添加三维位置编码。

没有深度时，则沿相机射线采样 64 个候选深度，通过特征相关性对候选三维位置加权。

因此，“不使用深度图”不等于“不需要几何信息”。无深度版本仍需要相机标定信息，不能直接理解为任意未标定 RGB 相机都可以使用。

在材料列出的 LIBERO-Plus 对应消融配置中，无深度版本达到 84.43%，使用真实深度为 84.68%。它说明该设置下学习到的空间特征可以部分替代深度输入，但不代表所有场景下都能恢复同样准确的几何。

4. 两个 Expert，分别支持控制与世界预测

UNITAS 采用两个关联的 Transformer Expert：

  • Point Dynamics Expert：预测 Action Flow 和 Scene Flow，学习机器人与环境的三维运动关系。
  • Action Expert：生成可以执行的末端动作 chunk，包括平移、旋转和夹爪开合。

两个分支通过观测表征关联，但 Action Expert 不直接读取未来 Flow token。

因此，系统可以有两种运行模式：

模式 运行内容 主要用途
Policy Mode 生成控制命令，跳过未来 Flow 生成 较低延迟的动作执行
World Model Mode 生成机器人运动，并据此预测场景点轨迹 预测和分析动作后果

三维动态训练可以改善控制表征，但这和“先预测多个动作的后果，再选出最佳动作”是不同的系统流程。UNITAS 的高成功率不能直接证明它在执行时进行了显式世界模型规划。

5. 策略与世界模型的实验结果

材料记载 UNITAS 约有 1.7B 参数，使用 Florence-2 预训练视觉语言骨干，并混合仿真、真实机器人和人手演示训练。

主要策略结果为：

评测 成功率
LIBERO 99.8%
LIBERO-Plus 89.1%
RoboTwin 2.0 Clean 92.94%
RoboTwin 2.0 Randomized 93.04%
VLABench Task Success Rate 56.2%

真实机器人 Organize Books 和 Pack the Ball 分别达到 90% 和 80%，每项评测 20 次。这支持在相应任务上的有效性，但真机样本量仍有限。

世界模型部分也有独立评测。在 RoboTwin 的动作条件场景预测中，Moving ADE 从 PointWorld 的 0.656cm 降到 0.427cm，约下降 35%。这是运动点预测误差的改善，与策略任务成功率属于不同维度。

作者报告在 RTX 5090 D 上：

  • Action-only：约 55.77ms / chunk。
  • 同时预测动作和两种 Flow，使用 1024 个 Scene Query：约 305.49ms。

两种延迟对应不同计算内容。不能用 action-only 的时间代表完整世界预测，也不能把每个 chunk 的时间直接等同于机器人单步控制周期。

6. 消融提醒：哪些信息真正帮助了控制

材料中两组消融尤其值得注意：

改动 LIBERO-Plus 成功率变化
加入 Scene Flow supervision 85.74% → 86.47%
去掉历史 Action Flow token 85.74% → 75.92%

在这些配置中，未来场景监督带来 0.73 个百分点提升，而移除历史动作信息导致 9.82 个百分点下降。它提示历史运动信息在该设置下十分重要，不能把整体性能提升全部归因于未来 Scene Flow 预测。

这也不是对所有模块贡献的完整排序：两种消融有不同改动方式，仍需结合误差范围和其他控制实验理解。它们与完整模型 89.1% 的主结果也不应混作同一配置。

7. 三维表示仍然有哪些边界

第一，明确三维坐标不等于获得完整物理模型。点轨迹可以描述运动，但并不自动保证力、摩擦、接触和关节约束一致。

第二，几何输入的质量很关键。深度误差、外参偏差、遮挡和点对应错误，都可能影响世界坐标下的特征和轨迹。

第三，Action Flow 是统一的运动描述，但机器人执行仍需要控制命令。不同本体可以具有相似的夹爪点轨迹，却有不同的可达范围和动力学限制。

第四，当前架构没有强制动作分支利用预测后果修正输出。因此，世界预测准确和策略表现好可以同时成立，但两者之间的决策因果关系仍需额外实验验证。

8. 与 EVA 的联系，以及下一步值得做什么

EVA 保留视频作为主要表示，用冻结 IDM 解码动作，再根据平滑性和限幅奖励优化视频生成器。UNITAS 则在表示层面把动作和世界变化统一到三维点轨迹中。

可以把两者理解为：

EVA：生成结果是否能被机器人执行？

UNITAS：动作和环境变化能否用共同的物理空间表示？

一个自然的后续方向，是把三维预测真正接入 Action Verification / Replanning：

  1. 提出候选动作，并获得对应的 Action Flow。
  2. 预测候选动作引起的 Scene Flow。
  3. 检查任务进展、几何约束和预测不确定性。
  4. 对不合适的候选重新规划，并在执行后用新观测纠正预测。

这需要验证候选动作与预测输入一致，也需要防止策略利用世界模型误差。上述流程是基于两篇工作的研究延伸，并不是 UNITAS 已经完成的执行机制。

UNITAS 最值得关注的是三维表示、物理时间和多来源运动数据之间的连接。下一步的问题，是如何让学到的世界预测不只帮助训练表征，还能直接改变机器人即将执行的动作。
